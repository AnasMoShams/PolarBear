# PolarBear — Roadmap

## Current Status

PolarBear currently provides a functional personal portfolio with:

* Home page
* About page
* Contact page
* Projects page
* Project details pages
* Project filtering
* Professional / Learning project types
* Add Project interface
* Project technologies
* Project image galleries
* Optional case studies
* Client-side project persistence

---

## Development Principle

Features should be added based on value rather than quantity.

The goal is not to make PolarBear as large as possible.

The goal is to make it:

* Clear
* Professional
* Fast
* Maintainable
* Useful
* Representative of the developer's skills
