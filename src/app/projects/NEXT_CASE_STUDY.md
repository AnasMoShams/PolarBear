# Next Case Study — How to Add

## Where It Goes

The next case study will be added to the **Learning Projects** section of the PolarBear portfolio.

Learning Projects are used for personal projects that I build to develop my skills in areas such as **Machine Learning, Data Science, and Data Analysis**.

## How to Add It

1. Open the **Add Project** page.
2. Select **Learning** as the project type.
3. Enter the project name and category.
4. Add the project description.
5. Add the technologies used.
6. Upload a cover image and optional gallery images.
7. Add the GitHub repository link.
8. Enable the **Case Study** option.
9. Document the case study using the following structure:

   * **Problem** — What problem or question was I addressing?
   * **What I Did** — What did I build, implement, analyze, or investigate?
   * **What Came of It** — What was the result, insight, or outcome?
10. Save the project.

The new project will appear in the **Learning Projects** section and will have its own project details page.
